# For Swetha

A cinematic digital love story — from **04 · 04 · 2022** to ∞.

## Stack

- React + TypeScript
- Tailwind CSS
- Framer Motion

## Run

```bash
npm install
npm run dev
```

## Music (optional)

Place a soft instrumental file at:

```text
public/audio/soundtrack.mp3
```

Music never autoplays. Use the small control in the corner to play or pause.
